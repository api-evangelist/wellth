# Wellth

> Wellth is a digital health company that applies behavioral economics to care-plan
> adherence. Members complete daily check-ins in the Wellth mobile app — photographing
> medications, logging blood pressure or glucose readings, confirming appointments and
> screenings — and earn financial rewards for staying on plan. Wellth sells to Medicare
> Advantage and D-SNP, Medicaid, ACA marketplace, employer and provider organizations.
>
> This file was generated by API Evangelist from publicly reachable Wellth surfaces on
> 2026-08-05. Wellth does not publish an llms.txt of its own.

## API surface

Wellth operates one production API and publishes no developer program for it.

- [Wellth GraphQL API](https://api.wellthapp.com/graphql): Single GraphQL endpoint
  (Apollo Server, internal application name `apiv4`) backing the member mobile app and
  the Wellth internal dashboard. **Introspection is disabled in production**, no schema
  or SDL is published, and there is no reference documentation, developer portal,
  OpenAPI, sandbox, or API key sign-up. Apollo CSRF prevention is enforced: requests
  must send a non-simple `Content-Type` or an `apollo-require-preflight` /
  `x-apollo-operation-name` header. Errors return a GraphQL `errors[]` envelope with
  `extensions.code`.
- Every path on `api.wellthapp.com` other than `/graphql` returns HTTP 200 with the
  plain-text body `Please use the /graphql route for access to useful data.` — a
  soft-404 catch-all. Do not treat a 200 from that host as evidence of a document.
